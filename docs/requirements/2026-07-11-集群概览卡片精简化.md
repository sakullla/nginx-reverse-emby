## 1. 需求摘要

- 问题句：我们要怎样让「集群概览」首页的顶部快捷入口和概览卡看起来更小巧、精致？
- 使用者：管理端用户。
- 为什么现在要做：上一版已完成功能布局（去掉离线节点、改成 4 列概览卡、新增证书卡），但卡片整体视觉体积仍偏大，需要进一步紧凑化。
- 目标与成功标准：
  - 顶部快捷入口与下方四张概览卡在视觉上明显更“小”且“精致”。
  - 保持一行 4 列概览卡布局不变。
  - 首屏一屏内可见核心内容。
  - 不丢失数据、链接、禁用状态、响应式行为。
- 最小可交付范围：仅调整 `DashboardPage.vue` 中上述卡片区域的样式与对应测试断言。
- 不做事项：
  - 不改动 `StatCard.vue` 组件本身。
  - 不改动后端接口与数据结构。
  - 不改动其他页面。

## 2. 规则与验收

- 关键业务规则：
  - 顶部快捷入口保留 3 个：查看全部节点、创建 HTTP 规则、创建 L4 规则；无可用节点时创建规则入口仍禁用。
  - 概览卡仍为 4 张：节点健康、HTTP 规则、L4 规则、证书；证书卡仍显示总数与 30 天内即将过期数。
  - 所有卡片保持可点击跳转（或禁用态）。
- 关键数据 / 信息：同上一版，数据展示内容不变。
- 边界与异常：
  - 小屏响应式下仍应可正常浏览，不溢出、不截断文字。
  - 图标与文字比例需保持可读性。
- 验收标准：
  - 视觉检查：截图圈出的两个区域相比当前版本明显更小、更精致。
  - 功能检查：所有入口/卡片链接、agentId 参数、禁用逻辑、证书过期提示均保持正确。
  - 自动化检查：`cd panel/frontend && npm run build && npm test -- DashboardPage.test.js` 通过。
- 验收与锚点映射：
  - R1：顶部快捷入口变小、变精致 → 视觉检查 + 测试覆盖。
  - R2：概览卡变小、变精致且保持一行 4 列 → 视觉检查 + 测试覆盖。
  - R3：数据与交互不破坏 → 功能检查 + 测试覆盖。
  - R4：构建与测试通过 → 自动化检查。
  - R5：只改 DashboardPage 及测试 → 代码范围检查。
