# 需求：SDK 节点地址与双栈监听句柄

日期：2026-08-18

## 一屏摘要

- 目标：公开 SDK 提供 Agent 节点对外地址投影，以及专用 TCP+UDP 同端口监听的只读绑定，供 Shadowsocks 等插件生成分享地址。（R1）
- 使用者：官方插件（先是 shadowsocks-server）与实现这些句柄的 Host。（R1）
- 范围：plugin-sdk 类型、校验与选择规则；不在本需求里改 HTTP 供应商或 L4 供应商目录。（R1、R2）
- 关键规则：对外主机按 DDNS、否则 IPv4、再否则 IPv6；永不投影 `0.0.0.0`、`::`、回环或 localhost。（R2）
- 成功标准：插件只消费句柄即可得到可分享主机和实际监听端口，不必自己探测公网 IP 或开公网套接字。（R1、R2）
- 不做事项：不改 HTTP 供应商跨主机模型；不把插件做成只能被 L4 选中的内部后端。（R3）

## 完整需求

### R1 Host 提供可注入的节点地址与双栈监听句柄

公开 `plugin-sdk/go` 声明：

- 节点地址快照：已配置的 DDNS 域名、IPv4、IPv6
- 只读来源接口，由 Host 注入，插件不探测公网 IP、不写 DDNS
- 双栈监听绑定：一个端口同时 TCP 与 UDP，以及读取该 `listener_ref` 实际绑定的句柄

插件通过这些句柄得到分享用的主机和端口。插件不自己打开公网监听。

验收：

- SDK 导出节点地址类型与 `NodeAddressSource`，以及双栈绑定类型与 `DualStackListener.Binding`。
- 选择规则在 SDK 内可单测：有 DDNS 用域名，否则 IPv4，再否则 IPv6。
- 通配或回环地址不能被选为分享主机。
- 绑定校验拒绝非 1–65535 端口，以及只开 TCP 或只开 UDP。

### R2 分享主机与 L4 填地址格式一致

SDK 提供把选出的主机和端口格式化成 `host:port`（IPv6 带方括号）的辅助函数，该字符串能填进现有 L4 `backend_host`/`backend_port` 所接受的主机形式。

验收：

- `203.0.113.10:8388` 与 `[2001:db8::1]:8388` 可由 SDK 辅助函数得到。
- `0.0.0.0`、`::`、`127.0.0.1`、`localhost` 不能被格式化成分享地址。
- 带 scheme 或路径的主机不能当作 L4 backend_host。

## 不做事项

### R3 不改 HTTP 供应商与 L4 供应商模型

本需求只增加 SDK 投影与监听绑定合同。不改变 HTTP backend-provider 的本机私有 socket 模型，不新增 L4 插件供应商目录。

验收：

- 交付不把 HTTP 供应商跨主机或 L4 插件供应商列为完成项。
- 现有 `http.backend-provider` 合同文件不被改成跨主机模型。
