## 1. 需求摘要

- 问题句：我们要怎样让 HTTP/L4/证书/Relay/WG 资源列表在保留节点记忆与新建便利的前提下，也能跨节点总览，并把节点从进入门槛改成普通筛选，同时增强卡片信息可读性？
- 使用者：控制面板运维/管理员，需要同时查看、筛选、管理多节点上的代理与基础设施资源。
- 为什么现在要做：
  - 现状：`QuickAgentSelect` 未选节点时页面空白，只能“先选节点再看列表”，跨节点排查/总览低效。
  - 连续新建/管理依赖节点上下文，不能每次进入都重置为全部，否则操作路径变长。
  - 跨节点浏览后，卡片若不露出所属节点与关键状态，列表不可用。
- 目标与成功标准：
  1. HTTP 规则、L4 规则、证书、Relay 监听、WireGuard 配置 5 个列表页支持「全部节点」查看。
  2. 节点是可切换的普通筛选条件（单节点 / 全部），不再是进入列表的强制门槛。
  3. 进入页默认恢复上次节点筛选；无记忆时：仅 1 个 local 节点自动选中，否则默认全部。
  4. 新建必须有归属节点：当前筛选为具体节点则沿用；当前为全部时需先指定；仅 1 个 local 时可自动带上。
  5. 卡片常显：所属节点、状态、主标识、1-2 关键参数、主操作。
- 最小可交付范围：
  - 上述 5 个列表页统一“节点筛选 + 全量可看 + 默认记忆”交互模型。
  - 卡片信息架构按最小必显集增强，使跨节点浏览可扫读。
  - 空状态从“请先选择节点”改为“无数据 / 无匹配筛选结果 / 无节点可管”等真实业务空态。
- 不做事项：
  - 版本策略页、规则详情页改造。
  - 表格优先的全面重做。
  - 全局导航/侧边栏信息架构重构。
  - 复杂多条件高级筛选平台。
  - 后端数据模型改造；若现有接口已支持全量或可按节点聚合，优先复用。

## 2. 规则与验收

### 关键业务规则

1. **页面范围**
   - 纳入：HTTP 规则、L4 规则、证书管理、Relay 监听器、WireGuard 配置。
   - 排除：版本策略、规则详情、节点管理首页、仪表盘等。

2. **节点筛选模型**
   - 节点选择器提供：具体节点列表 + 「全部节点」。
   - 选择具体节点：仅展示该节点资源。
   - 选择全部节点：展示所有节点资源汇总列表。
   - 节点筛选与关键字搜索可并存；筛选变化后列表与计数同步更新。

3. **默认与记忆**
   - 进入任一纳入列表页：优先恢复该用户上次使用的节点筛选状态。
   - 无可用记忆时：
     - 若系统中仅有 1 个 local 节点：自动选中该节点。
     - 否则：默认「全部节点」。
   - 用户主动切换节点/全部后，应被记住，供下次进入使用。

4. **新建/添加**
   - 新建资源必须绑定归属节点。
   - 当前筛选为具体节点：新建表单自动带上该节点，无需再选。
   - 当前筛选为「全部节点」：点新建时必须先指定归属节点，或在表单内完成节点选择后才能提交。
   - 系统仅有 1 个 local 节点时：新建可自动带上该节点。

5. **卡片展示（主视图目标）**
   - 每条卡片在跨节点场景下至少常显：
     - 所属节点
     - 启停/生效等状态
     - 对象主标识（如规则名/域名/监听地址/Profile 名等，按资源类型映射）
     - 1-2 个关键参数（如端口、上游、流量摘要等）
     - 主要操作（如编辑、启停；删除等危险操作可次级呈现）
   - 未选具体节点时，卡片不得依赖“页面级当前节点”才能理解归属。

6. **空状态与加载**
   - 不再以“未选节点”作为主要空态。
   - 区分：加载中、系统无节点、当前筛选无数据、关键字无匹配。

### 关键数据 / 信息

- 列表项需可识别所属节点（节点 id/名称展示策略由方案定，需求要求用户能区分归属）。
- 列表计数应反映当前筛选结果（全部或单节点 + 搜索）。
- 节点列表来源沿用现有 agents 数据。

### 边界与异常

- 上次记忆的节点已不存在/离线：回退规则同“无记忆”（仅 1 local 自动选中，否则全部），并避免空白死页。
- 全部节点下数据量大时：允许技术方案做分页/虚拟列表/聚合策略，但不得回到“必须先选节点才能看”。
- 某些操作天然依赖单节点上下文（如诊断、复制到当前节点）：在全部视图下需明确要求先选节点，或操作内指定目标节点；不得静默失败。
- 无任何节点时：引导去节点管理加入节点，而不是假装有可筛选数据。

### 验收标准

1. 打开 HTTP/L4/证书/Relay/WG 任一列表页，在存在多节点数据时，可不先手工选节点就看到列表（依赖记忆或默认全部/单 local）。
2. 筛选切到「全部节点」后，列表同时展示多个节点的资源，且每条卡片可见所属节点。
3. 筛选切到某一节点后，列表仅显示该节点资源；新建自动带该节点。
4. 刷新或再次进入同页，节点筛选恢复为上次选择。
5. 删除记忆节点或首次使用时，回退行为符合 R3。
6. 当前为「全部」时点新建：不能在无归属节点的情况下成功创建资源。
7. 仅 1 个 local 节点时，进入页与新建均可自动带上该节点。
8. 卡片在全部视图下仍可完成“识别对象 → 判断状态 → 执行主操作”的扫读路径。
9. 版本策略页与规则详情页行为保持现状（本次不验收其改造）。

- 验收 4/5 → R3
- 验收 6/7 → R4

- 验收 9 → R6, R7
