## 1. 需求摘要
- 问题句：我们要怎样进一步调整控制面板「集群概览」首页，使其概览卡片更紧凑并在首屏展示节点、HTTP 规则、L4 规则、证书四类关键信息？
- 使用者：控制面板管理员/运维人员
- 为什么现在要做：前序首页重新设计已上线，用户在实际预览后发现 3 张大卡占用过多首屏空间，且证书状态是值得在概览层暴露的关键运维信息。
- 目标与成功标准：
  - 首页概览区以一行 4 列紧凑卡呈现节点健康、HTTP 规则、L4 规则、证书管理
  - 顶部快捷入口去掉「查看离线节点」，剩余 3 个改为紧凑图标+文字卡片
  - 高频任务 2 次点击内可达
  - 构建与测试通过
- 最小可交付范围：只修改 `DashboardPage.vue` 及对应测试文件
- 不做事项：
  - 不添加版本策略、Relay 监听器、WireGuard 配置概览卡
  - 不修改其他页面、路由、全局组件
  - 不做证书管理页本身的重构

## 2. 规则与验收
- 关键业务规则：
  - 证书管理卡仅做概览展示，点击后跳转到 `/certs`
  - 节点健康卡继续展示在线/总数 + 离线数量
  - HTTP 规则卡、L4 规则卡继续展示各自总数
  - 快捷入口的创建规则链接继续携带默认 `agentId` 参数
- 关键数据 / 信息：
  - 节点：在线数、总数、离线数
  - HTTP 规则：总数
  - L4 规则：总数
  - 证书：总数、即将过期数
- 边界与异常：
  - 无证书时证书卡显示 0 并仍支持跳转
  - 无 agent 时创建规则入口的降级策略保持与前序设计一致
- 验收标准：
  - AC1：首页顶部只出现「查看全部节点」「创建 HTTP 规则」「创建 L4 规则」三个图标+文字快捷入口，无「查看离线节点」
  - AC2：健康概览区为 4 张紧凑卡横向一行排列，依次/分别为节点健康、HTTP 规则、L4 规则、证书管理
  - AC3：证书管理卡显示证书总数与即将过期数量，并链接到 `/certs`
  - AC4：4 张概览卡在常规屏幕下首屏可见，不出现过度滚动
  - AC5：创建 HTTP/L4 规则入口链接包含默认 agentId；无 agent 时入口被禁用或降级为跳转到列表页
  - AC6：页面无版本策略、Relay 监听器、WireGuard 配置引用
  - AC7：构建通过，新增/现有测试通过
- 验收与锚点映射：
  - AC1 → R1
  - AC2 → R2、R4
  - AC3 → R3
  - AC4 → R4
  - AC5 → R5
  - AC6 → R8
  - AC7 → R6
