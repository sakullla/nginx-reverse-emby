# 需求：插件页面与动态表单重构

日期：2026-08-13

## 一屏摘要

- 目标：全新设计插件相关 4 个页面，并把声明式 UI 升级为能编辑完整配置（含嵌套对象与数组）的动态表单（R1、R2）
- 使用者：管理员（配置）、resource.write 成员（动态动作）、只读成员（查看）（R1）
- 范围：4 页全量重设计 + 声明式 UI 词表扩展（嵌套 / 数组 / 条件显示 / 校验提示）+ 无 ui_schema 兜底表单（R1、R2）
- 关键规则：以大众/主流 UI 惯例为准；插件不得注入前端代码，新增组件与条件表达式经后端白名单校验（R1、R3）
- 成功标准：任意合法 config_schema 可完整编辑保存；交互符合主流惯例；非法 UI 被拒绝；测试全绿（R2、R3、R4）
- 不做事项：不改插件运行时/执行面与业务存储语义；不动非插件页面（R5、R6）

## 完整需求

### R1 插件相关页面全新设计

全新设计插件相关全部 4 个前端页面——已安装列表（`PluginsPage`）、配置详情（`PluginDetailPage`）、市场（`PluginMarketplacePage`）、仓库源（`PluginRepositoriesPage`），统一设计语言与信息架构。整体遵循大众/业界主流的 UI/UX 惯例（标准表单布局、按钮、确认弹窗、导航、空态、加载与错误态等熟悉模式），替换现有反直觉的交互。

主要使用者：管理员（可配置）、有 `resource.write` 权限的成员（可触发动态动作）、只读成员（仅查看）。

验收：

- 4 个页面均完成全新设计，视觉与交互风格一致。
- 交互符合大众/主流设计惯例，无需说明即可理解并完成主要操作（查看列表、编辑配置、安装/升级、管理仓库源）。
- 桌面与移动视口下无布局回归。

### R2 声明式 UI 动态表单升级

将插件自描述的声明式 UI（`ui.schema.json`）升级为唯一、完整的配置编辑入口。词表在保留现有 text / number / toggle / select / secret / textarea / notice 组件与 submit / reset / dynamic 动作的基础上，新增：

- 嵌套对象渲染
- 数组 / 可重复分组（增删 / 重排）
- 条件显示（字段随其他字段值显隐，使用受限表达式）
- 校验提示（展示 min / max / pattern / minLength 等规则与行内错误）

插件未提供 `ui_schema` 时，用增强后的 Schema 自动生成表单兜底，补齐嵌套对象与数组的编辑能力，保证任何合法配置都可编辑。

验收：

- 给定含嵌套对象与数组的合法 `config_schema`，可在配置页完整编辑所有字段并保存生成 revision。
- 数组字段可新增、删除、重排条目；条件显示按声明规则显隐字段；校验提示在输入越界时给出可见错误。
- 无 `ui_schema` 的插件仍可编辑其完整配置（含嵌套 / 数组）。
- 秘密字段的留空保留、清除、轮换语义不变。

### R3 安全边界不变

插件仍不能向宿主前端注入 HTML、JavaScript、CSS 或远程组件。声明式 UI 全部数据经后端白名单校验，前端只用宿主内置组件渲染。新增的组件类型与条件表达式同样纳入后端校验范围（类型、绑定、约束、表达式语法与预算上限），非法数据被拒绝。

验收：

- 包含注入（HTML / JS / CSS / 远程组件 / URI）、越界绑定、绑定矛盾或非法条件表达式的声明式 UI 被后端拒绝，前端不执行插件提供的任何代码。
- 新增组件与条件表达式的渲染仅由宿主内置组件完成。

### R4 契约与兼容

当前插件配置渲染并未实际支持：官方市场包仅带 `config_schema` 而无 `ui_schema`，声明式 UI 从未投入使用，兜底表单只处理扁平标量，因此**无需版本迁移，也无需提升 `schema_version`**。声明式 UI 词表在现有 `schema_version` 1 契约上直接扩展以适配插件配置渲染（嵌套对象 / 数组 / 条件显示 / 校验提示），不引入版本迁移或版本号提升。动态动作（含签名权限 / 能力校验）与秘密字段（留空保留 / 清除 / 轮换）行为保持不变。后端声明式 UI 校验与 SDK 插件 manifest / schema 同步升级；前端 vitest 与后端 go test 用例更新后全部通过。

验收：

- 任意合法 `config_schema`（含嵌套对象 / 数组）可完整编辑并保存生成 revision。
- 动态动作的触发与权限 / 能力校验行为不变；秘密字段语义不变。
- 升级后前端与后端测试套件运行全部通过。

## 不做事项

### R5 不扩展插件运行时 / 执行面与业务存储语义

本次不改插件运行时与执行面（go-agent、wasm / process 宿主、插件业务逻辑）以及插件的业务存储 / 校验语义；仅扩展「声明式 UI 契约」所需的后端校验（`declarative_ui` 词表与条件表达式校验）。

验收：

- 插件运行时、go-agent、wasm / process 宿主的对外行为与存储语义无变化。
- 后端改动限于声明式 UI 契约校验。

### R6 不动非插件页面

本次重构仅涉及插件相关 4 个页面及其表单 / 契约，不修改控制面其他页面（规则、L4、证书、PKI、Relay、版本、设置、访问、Dashboard 等）。

验收：

- 非插件页面的路由、行为与视觉保持不变。
