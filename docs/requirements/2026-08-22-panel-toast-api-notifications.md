# 需求：面板接口通知与异常提醒统一走 Toast

日期：2026-08-22

## 一屏摘要

- 目标：面板操作者在接口成功、失败或异常时，一律通过现有全局 toast 看到提醒，不再把这类消息嵌进列表或页面横幅（R1）
- 使用者：控制面板操作者，尤其是插件部署、启停、市场安装以及仍用内嵌横幅的其它接口动作（R1）
- 范围：所有「接口动作结果」的成功/失败提醒，包括插件与其它仍内嵌横幅的模块（R1、R2）
- 关键规则：复用现有 toast；动作级提交错误走 toast；字段校验、登录错误、资源持久状态、整页空状态、配置生效进度条保持原样（R2）
- 成功标准：插件部署失败出现 toast 且详情页列表上方不再出现错误条；同类接口动作同样走 toast（R1、R2）
- 不做事项：不改 toast 视觉、不把资源状态/诊断/操作时间线改成 toast、不改后端错误文案（R3）

## 完整需求

### R1 接口动作结果使用现有 Toast

面板里所有接口动作的成功、失败和异常提醒，都通过现有全局 toast（`messageStore` + `StatusMessage`）展示。操作者不应再在列表、页面横幅或弹窗内嵌条里寻找这类结果。

覆盖范围包括但不限于：

- 插件部署、发布入口、更新入口、保存实例配置、启停、回滚、卸载、删除实例、删除入口、重试 Agent revision
- 插件市场安装、升级与相关提交失败
- 插件仓库源的提交失败
- 仍用内嵌横幅展示结果的其它接口动作，例如用户/资源组的成功与失败提示、配置生效列表上的重试/回滚/隐藏失败、PKI 操作提交失败

成功类接口通知同样走 toast。例如插件部署成功后，除关闭弹窗并刷新页面外，还要给出成功 toast；目前关弹窗后没有提示的动作需补上。

验收：

- 在插件详情页执行部署并被接口拒绝时，出现错误 toast，详情页列表/任务区上方不再出现内嵌错误条
- 插件部署、发布或配置保存成功时，出现成功 toast
- 插件启停、卸载、市场安装/升级等接口失败时，出现错误 toast，对应页面不再用 `plugin-alert` 或等价横幅展示该次动作结果
- 用户/资源组、操作重试、PKI 提交等原先内嵌的动作成功/失败提示，改为 toast 后，原横幅不再显示该次动作结果
- 同一时刻的 toast 文案能让操作者理解发生了什么（沿用现有可读错误文本，不要求改后端文案）

### R2 动作级错误与应保留的原位信息

动作级提交错误（例如未选节点、缺少资源组、接口返回失败）使用 toast，而不是页面或弹窗里的结果横幅。

下列信息不是「接口动作通知」，保持原位：

- 表单字段级校验（贴在对应输入旁的 `form-error` / 字段错误）
- 登录页、令牌登录框的认证错误
- 资源自身的持久状态，例如证书/节点/DDNS 的 `last_error`、节点同步失败原因、操作时间线上的历史错误
- 整页加载失败时的空状态（例如插件详情读不到时的 EmptyState 与重试）
- 配置生效进度条、诊断报告、权限只读说明、以及「当前没有可选择的节点」这类持续性引导

弹窗内的持续性 blocker（例如当前身份不能提交、缺少可见资源组导致无法开始）可以保留为引导，但一次提交触发的失败必须走 toast。

验收：

- 插件部署弹窗中未选节点或未填入口域名并提交时，以 toast 提示，不再只靠弹窗内错误条
- 字段级校验（例如规则表单域名格式错误）仍显示在对应输入旁，不改为 toast
- 证书列表或卡片上的 `last_error`、节点详情的上次同步失败原因仍显示在资源上
- 插件详情整页加载失败时仍使用空状态与重试，而不是只弹 toast 后留空白页
- 配置生效列表仍展示进行中/失败的操作进度；仅「重试/回滚/隐藏」这次点击的接口失败改为 toast

## 不做事项

### R3 不改 Toast 视觉、资源状态与后端文案

不重新设计 toast 组件外观、时长或交互。不把资源持久状态、诊断报告、操作时间线或仪表盘关注条改成 toast。不修改后端返回的错误码或错误文案；前端只把现有可读文本送到 toast。

验收：

- toast 仍使用现有 `StatusMessage` 与 `messageStore` 行为（类型、自动消失、hover 暂停）
- 证书/节点/操作历史等资源状态字段仍在原位置展示
- 后端错误响应结构与文案不作为本次交付内容

## 来源

- 用户请求：所有接口通知与异常提醒应使用现有系统 toast，而不是内嵌到列表；典型例子是插件部署报错
- `panel/frontend/src/stores/messages.js` 与 `panel/frontend/src/components/StatusMessage.vue`：现有全局 toast
- `panel/frontend/src/App.vue`：全局挂载 `StatusMessage`
- `panel/frontend/src/pages/plugins/PluginDetailPage.vue`、`PluginDeployModal.vue`、`PluginMarketplacePage.vue`：插件动作结果目前内嵌为 `plugin-alert`
- `panel/frontend/src/hooks/useRules.js` 等：规则/节点/证书等模块已用 `messageStore` 作为对照
