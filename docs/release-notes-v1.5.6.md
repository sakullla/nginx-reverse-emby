# Nginx-Reverse-Emby v1.5.6

对照 v1.5.5 的补丁版本。版本号由发布 tag 注入构建，镜像标签为 `sakullla/nginx-reverse-emby:1.5.6`。

## 修复与体验改进

- 修复 Go agent 集成测试发现阶段因测试辅助函数被构建标签排除而无法编译的问题。
- 重新设计樱花日间与夜间主题，调整粉紫渐变、背景层次、品牌花瓣标识及按钮文字对比度。
- 优化插件市场手机端布局、搜索筛选、列表卡片、详情与权限确认弹窗，减少留白并保持操作按钮可见。
- 已知插件操作进行中时显示进度入口；安装前刷新状态，避免重复提交。失败信息留在弹窗内，下载重试后需再次确认权限才能安装。
- 插件详情直接展示操作进度，支持手动刷新；市场加载失败显示真实错误，不再回退为可安装的预览数据。

## 验证

- 前端 96 个测试文件、912 项测试通过，生产构建通过。
- 日间与夜间主题在桌面、平板及 390/360 像素手机宽度完成截图检查，额外检查 740 像素手机高度；未发现浏览器错误或视口溢出。
- Go 快速与完整测试、Linux 集成测试发现及受影响包的集成测试通过。
- 截图使用合成 API 数据，不代表线上后端验收；本地 Docker 镜像构建未验证，交由发布 CI 执行。

## 升级

```sh
docker compose pull
docker compose up -d
```

若使用固定镜像版本，请先将镜像标签改为 `1.5.6`。镜像需等待发布 CI 构建完成后可用。
