# Nginx-Reverse-Emby 中文社区推广方案与方向

日期：2026-10-05
状态：方向建议稿；渠道与节奏可按实际账号、版规和精力调整。

## 1. 定位

主定位：

> 把已经优化好的线路或中转机，变成电视、盒子等所有设备的加速入口：反代 Emby 等媒体服务、HTTPS 证书自动签发续期、安全 L4 转发与反向 L4 内网穿透，一个纯 Go 面板全包，不用手写 Nginx。

社区口吻备选：

> 线路已经优化好了，别只给自己用：让电视、盒子、不方便挂代理的设备直接用上加速线路；顺带把 HTTPS 证书、L4 转发、反向内网穿透都交给面板。

统一认知（本次澄清确认）：

- 产品是通用 HTTP/HTTPS 反代 + L4 TCP/UDP 转发工具；Emby / Jellyfin 只是示例场景之一，不做 Emby 专用优化。
- 目标用户不是「自建 Emby」的人，而是已有优化线路 / 中转机的用户，典型用途：反代加速（电视等不便代理的设备）、免维护 HTTPS、安全 L4 转发、反向 L4 内网穿透。
- 差异化卖点：纯 Go 无 Nginx 依赖、多节点 Agent、Relay 隧道（NAT 后可用）、流量统计与月度额度、ACME 自动证书、插件市场、中文文档与一键脚本。

长尾：

- GitHub：README、Release、中文 awesome 清单收录。

- 搜索引擎：文档站 SEO，覆盖「Emby 反代」「NPM 替代」「端口转发面板」「内网穿透」等词。

渠道通用注意：先读版规；不硬广；帖子与截图不出现真实 token、域名、IP；步骤必须可复现。

## 8. 需要产品 / 研发配合的推广资产（另行立项）

- 在线只读体验站：零部署先体验，优先级建议最高；安全上只渲染假数据，不作为真实面板对外。
- README 首屏 10–20 秒 GIF 或短视频。
- 文档站「常见失败 5 分钟排查」页面与配套视频。
- 四类场景示例库（优化线路反代加速、免维护 HTTPS、安全 L4 转发、反向 L4 内网穿透；文档级示例，不做 Emby 特化）。

## 9. 风险与边界

- 版规风险：以教程形式发布，先读版规；避免重复刷帖。
- 安全示范：教程必须引导 HTTPS + 32 位以上随机令牌，示例全部脱敏。
- 预期管理：临时 HTTP 只是过渡方案；证书签发依赖 DNS 正确。
- 维护成本：集中答疑并沉淀 FAQ；issue 模板引导附版本与日志。
- 用途边界：教程示例限于用户自有服务与自有设备，不涉及未授权访问他人网络。
- 不购买刷量 / 刷 Star，不拉踩竞品；对比保持可验证。
